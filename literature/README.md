# Literature Review

This directory contains the core scientific papers and background references supporting this Master's thesis on **Self-Interacting Dark Matter (SIDM)** and **early Supermassive Black Hole (SMBH) seed formation**. All files are stored as open-access preprints (arXiv).

---

## Directory Structure

* **`01-core-references/`** — Primary reference paper forming the theoretical and modeling foundation of the thesis.
* **`02-sidm-theory/`** — Foundational and recent works on SIDM particle models, cross-section constraints, and gravothermal core collapse.
* **`03-bh-seeds-accretion/`** — Literature covering early SMBH seeding mechanisms, super-Eddington accretion physics, and high-redshift observational constraints (including JWST *Little Red Dots*).
